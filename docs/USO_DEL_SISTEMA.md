# Uso Del Sistema

## Acceso

La portada ofrece **Iniciar sesión** y **Primer ingreso**. Todo usuario se autentica con su contraseña; la IP se conserva exclusivamente para control interno y auditoría.

## Usuario

1. Registre el primer ingreso y espere aprobación cuando esté habilitada.
2. Abra **Nuevo ticket**.
3. Indique categoría, prioridad, justificación y descripción.
4. Adjunte evidencia opcional.
5. Consulte respuestas y estado desde **Tickets**.
6. Cuando el ticket sea asignado, el detalle muestra **Usted está siendo atendido por** junto al nombre del integrante del Equipo de Sistemas.
7. La campana muestra asignaciones, respuestas y cierres en vivo; al seleccionar una notificación abre el ticket correspondiente.
8. Si un incidente cerrado continúa, escriba el motivo y seleccione **Reabrir ticket**.

## Equipo De Sistemas

El panel presenta indicadores, usuarios pendientes, últimos tickets y accesos. Puede aprobar usuarios, asignar tickets, comentar, subir archivos, agregar constancias, resolver, cerrar, cancelar, reabrir, exportar reportes y revisar auditoría.

Las notificaciones y cambios de tickets llegan en vivo. Una vez cerrado o cancelado un ticket, la interfaz muestra el resultado final y oculta las acciones que ya no aplican; el backend también impide repetirlas.

## Estados

`Abierto`, `En proceso`, `Esperando respuesta del usuario`, `Resuelto`, `Cerrado`, `Reabierto` y `Cancelado`.

## Prioridades

`Baja`, `Media`, `Alta` y `Crítica`. Toda prioridad requiere una justificación escrita.
