# Frontend

Aplicación React + Vite + TypeScript + Tailwind CSS de Mesa de Ayuda CECASEM.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

La variable `VITE_API_BASE_URL` se configura como `http://192.168.88.123:47821/api`. Para generar recursos de producción use `npm run build`.
